# Security Policy

## Supported versions

Security fixes are made on actively maintained releases on `main`.

## Reporting a vulnerability

Please do **not** open public issues for security vulnerabilities.

Report vulnerabilities privately via:

1. GitHub Security Advisories (preferred):  
   `https://github.com/Artic0din/PowerSync/security/advisories/new`
2. If needed, contact the maintainer through GitHub with a private report.

Include:

- A clear description of the issue.
- Reproduction steps or proof of concept.
- Impact and affected versions/components.

We will acknowledge valid reports and coordinate remediation and disclosure.
