# Security Policy

PowerSync is a fork of [bolagnaise/PowerSync](https://github.com/bolagnaise/PowerSync). For upstream security concerns, please report there.

## Fork-specific issues

Open a GitHub issue with `[security]` in the title or contact via the email in profile.

## Scope

This fork primarily mirrors upstream. Fork-specific code lives under `audit/` branches and `docs/audits/`. Production code identical to upstream unless explicitly noted in commit messages.

## Supported versions

Tracks upstream release cadence. Latest fork sync date in commit log.
