# Decisions log

Architectural and scope decisions for this repository, newest last.
Record a decision when a choice constrains future work: dependency boundaries, data
shapes, deployment targets, protocol contracts, or anything a later change would have to
argue against.

Format, one entry per decision:

```markdown
## D1 — Short title

**Decision:** what was chosen, stated so it can be checked against the code.

**Reasoning:** why this option over the alternatives, and what it costs.
```

Do not record routine implementation detail here; the code and its tests carry that.
Do not backfill entries from memory — a decision undocumented at the time stays
undocumented, and is better raised as a fresh decision when it next comes up.
