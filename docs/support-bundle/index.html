Create a sanitised support bundle

This tool runs only in your browser. It removes credentials and replaces personal identifiers consistently before you attach logs to a public GitHub issue.

Create bundle

Choose one text log up to 512 KB.

What changes

Credentials, authorization headers, cookies, and webhook URLs are removed. IP and MAC addresses, VINs, email addresses, usernames, serial numbers, and home paths receive stable placeholders. Timestamps, versions, errors, stack traces, and ordering remain.

Always review the downloaded file before uploading it. If a credential was already posted, revoke or rotate it; deleting a link is not a confidentiality guarantee.
