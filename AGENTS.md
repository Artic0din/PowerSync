# AGENTS Instructions

This repository is a Python Home Assistant custom integration.

## Scope

- Keep changes non-invasive and focused to the request.
- Do not move or relocate application code unless explicitly requested.

## Workflow expectations

- Reuse existing repository tooling and scripts.
- Use the pull request template at `.github/pull_request_template.md`.
- Select exactly one change-type checkbox in PR descriptions.
- If code or configuration changes, update one or more of:
  - `README.md`
  - `docs/`
  - `CHANGELOG.md`
