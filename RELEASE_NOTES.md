## What's Changed

**Auto-Apply now keeps the manual Optimizer Reserve visible**

The Smart Optimization settings API now keeps **Optimizer Reserve** at the user's saved manual minimum while exposing the live forecast-adjusted floor separately as **Auto-Applied Reserve**. Changing forecasts can move the calculated floor without replacing or hiding the manual setting, and disabling Auto-Apply still restores the active optimizer floor to that manual value.

Update available via HACS
