## What's Changed

**Rolling tariff forecasts now show the correct day**
The PowerSync mobile dashboard and tariff schedule sensor now label each rolling 24-hour price with the calendar day it actually represents. Elapsed clock times that contain tomorrow's forecast no longer appear as Today, while recurring static TOU schedules keep their existing wall-clock labels. The schedule retains the exact tariff timezone and refresh boundary across half-hour and midnight transitions.
