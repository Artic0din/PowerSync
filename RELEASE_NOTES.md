## What's Changed

**Mobile configuration now follows the Home Assistant currency**

PowerSync's mobile configuration and electricity-provider endpoints now return the configured Home Assistant currency together with its major and minor price units. Generic and custom tariffs therefore no longer fall back to Australian dollars in mobile clients when the Home Assistant installation uses GBP, EUR, NZD, or another supported currency.

**Commercial licensing enquiries have a direct contact**

The README now directs commercial licensing enquiries to dev@powersync.cc instead of the community Discord server.
