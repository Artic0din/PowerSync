## What's Changed

**The 24-hour Action Plan now shows every scheduled action**
Busy optimizer plans with more than 24 consolidated action ranges are no longer truncated after the 24th row. Charge, export, idle, and self-consumption changes later in the same 24-hour view now remain visible in the dashboard's existing scrollable Action Plan.
